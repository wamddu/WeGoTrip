# 모여행 데모

`demo` 브랜치에서 만든 그룹 여행 관리 React Native 앱입니다. Expo SDK 57 / React Native 0.86 프로젝트의 기존 의존성을 사용합니다.

## 실행

Node.js 22.18 이상 권장. 처음 설치하는 환경에서는 `npm ci`를 실행합니다.

```sh
npm run web -- --port 8087
```

브라우저에서 `http://localhost:8087`을 엽니다.

이 PC에서는 전역 `npm` 실행 경로가 손상되어 있어, 설치된 Expo 실행 파일로 직접 시작할 수 있습니다. PowerShell의 `frontend` 폴더에서 실행합니다.

```powershell
.\node_modules\.bin\expo.cmd start --web --port 8087
```

Expo 개발 서버는 다음으로 시작합니다.

```sh
npm start
```

서버가 출력하는 QR/주소를 해당 SDK를 지원하는 Expo Go 또는 개발 빌드에서 엽니다. 네이티브 실행에는 호환되는 기기·개발 환경이 별도로 필요합니다.

## 체험할 수 있는 기능

- 요약: 여행 소개, 공지, 다가오는 일정, 준비물 체크, 지출 합계.
- 일정: 날짜·파티 필터, 일정 추가·수정·삭제. 파티 필터에서도 전체 합류 일정은 유지합니다.
- 지도: 실제 지도 대신 예시 장소 배치. 저장 장소 검색·추가·선택 및 일정 추가 연결.
- 정산: 지출 추가, 결제자·부담 멤버 선택, 균등 분담, 멤버별 결제·부담액과 송금 방향 계산.
- 대화: 로컬 메시지 작성·전송, 공지 확인·수정.
- 여행 전환: 상단 여행명 또는 모여행 로고에서 목록을 열어 새 여행을 만듭니다. 여행마다 데이터가 분리됩니다.
- 준비물: 체크 상태 변경과 항목 추가.

## 데모 범위

로그인과 서버 연결 없이 메모리의 예시 데이터를 사용합니다. 새로고침이나 앱 재시작 시 입력 데이터는 초기화됩니다. 멤버 4명과 파티 2개는 고정입니다. 새 여행도 같은 예시 멤버로 시작하며 여행 기간은 최대 14일입니다.

실제 GPS·지도 검색 API, 친구 초대, 영수증 OCR, 실시간 채팅, 송금, AI 기능은 연결되지 않았습니다. 지도에 표시하는 순서는 예시 장소 배치이며 실제 지리·최적 경로가 아닙니다. 금액은 원화의 양의 정수(최대 1억원)만 지원합니다. 나누어떨어지지 않는 금액은 선택된 멤버의 고정 순서로 1원씩 배분합니다.

## 검증

```sh
npm run typecheck
npm run test:demo
npx expo export --platform web
```

정산 검사는 합계 보존, 1원 단위 잔액, 결제자가 부담 대상에서 빠진 경우와 빈 지출을 포함합니다. 브라우저 검증은 웹에서의 실행 확인이며 실제 Android/iOS 기기 검증과는 별도입니다.

현재 PC에서 TypeScript 검사와 정산·날짜 검사, 웹 export, Android/iOS JavaScript 번들 생성을 통과했습니다. npm 경로 오류가 있으면 ` .\node_modules\.bin\tsc.cmd --noEmit`와 `node --experimental-strip-types scripts/test-demo.mjs`로 직접 검사할 수 있습니다.

## 코드 위치

- `src/demo/demo-app.tsx`: 화면, 탭, 입력 모달과 메모리 상태.
- `src/demo/model.ts`: 예시 데이터, 날짜 범위와 정산 계산.
- `src/demo/ui.tsx`: 공통 색상·아이콘·버튼·입력 컴포넌트.
- `src/app/index.tsx`, `src/app/_layout.tsx`: 데모 진입점.

기존 시작 화면의 `Hello` 수정은 루트 저장소 `tmp/frontend-before-demo.patch`에 작업 전 패치로 보관했습니다. 앱은 단일 Expo 경로 내부의 로컬 탭 상태로 동작하며, 제품 개발 단계에서는 화면별 라우트와 영구 저장소로 분리할 수 있습니다.
