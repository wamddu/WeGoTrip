# 투표 자동 마감 변경안

상태: 2026-10-24 사용자의 “구현 진행해” 승인 후 구현 및 연결된 WeGoTrip DB에 012 적용 완료. 적용 전 스키마는 `tmp/chat-diagnostics/schema-before-012-1792817530332.sql`에 보관했다. 기존 투표 2개는 자동 마감 없는 NULL 상태로 유지했다.

## 필요한 DB 변경

현재 `chat_poll`에는 수동 마감 여부인 `closed`만 있다. 서버 재시작과 여러 기기에서도 마감 시각을 동일하게 유지하려면 마감 시각 저장이 필요하다.

별도 `backend/db/migrations/012-chat-poll-deadline.sql` 마이그레이션으로 다음 두 항목을 추가했다. 실제 파일은 컬럼과 인덱스 존재 여부를 검사해 재실행할 수 있게 작성했다.

```sql
ALTER TABLE chat_poll
  ADD COLUMN closes_at TIMESTAMP(6) NULL DEFAULT NULL;

CREATE INDEX idx_chat_poll_deadline ON chat_poll(closed, closes_at);
```

- `closes_at = NULL`: 자동 마감 없음. 기존 투표는 모두 이 상태로 유지한다.
- `closes_at` 지정: 해당 시각부터 신규 투표, 변경, 취소를 차단한다.
- 인덱스는 자동 마감 작업에서 아직 열려 있고 기한이 지난 투표를 찾는 데 사용한다.
- 기존 질문, 항목, 장소 연결, 투표 내역은 변경하지 않는다. MySQL DDL은 암시적으로 커밋되므로 적용 전 스키마를 보관하고 변경 대상과 기존 컬럼 유무를 확인한다.

## 화면과 API

- 투표 생성 화면에 기본으로 꺼진 작은 `자동 마감` 토글을 제공한다.
- 켜면 빠른 시간 선택과 날짜·시간 직접 지정을 제공한다. 지나간 시각은 허용하지 않는다.
- 생성 API에 선택적인 `closesAt`을 추가한다. 생략하거나 NULL이면 기존처럼 수동 마감하며, 지정할 때는 시간대가 포함된 ISO 8601 시각을 받는다.
- 투표 응답에 `closesAt`과 시간 표시 보정용 서버 현재 시각을 제공한다. 화면에는 마감 일시와 남은 시간을 표시하고, 기한이 되면 참여 버튼을 비활성화한다.
- 작성자와 여행 방장은 기존처럼 예정 시각보다 먼저 수동 마감할 수 있다. 생성 후 마감 시각 편집은 이번 범위에 포함하지 않는다.

## 서버 처리

- 실제 투표 가능 여부는 서버 시각으로 판단한다. 클라이언트 시계가 다르거나 자동 마감 작업이 지연되어도 마감 후 요청은 거절한다.
- 주기 작업은 만료된 투표를 `closed = TRUE`로 바꾸고 메시지 revision을 올린 뒤 커밋 후 기존 WebSocket 이벤트로 알린다. 서버가 꺼져 있던 동안 지난 마감도 재시작 후 처리한다.
- 투표·수동 마감·자동 마감이 동일한 여행 잠금 순서를 지키도록 처리하고, 이미 마감된 투표에는 중복 마감 이벤트를 만들지 않는다.
- 조회 응답에서도 예정 시각을 기준으로 마감 상태를 판단한다. 기존 투표와 자동 마감 미설정 투표의 동작을 유지한다.

## 검증과 적용 순서

승인 후 구현 및 H2 테스트 → 프런트엔드 검사 → 연결된 DB의 스키마와 백업 확인 → 승인된 추가 마이그레이션 적용 → 실제 컬럼·인덱스 확인 순서로 진행한다. 백엔드 실행 또는 재시작이 필요한 경우 현재 실행 상태를 확인한다.

검증 범위는 마감 직전·정각·직후 요청, 지난 시각 입력, 시간대 변환, 마감 후 투표 변경·취소 차단, 수동 조기 마감, 중복 생성 요청, 자동 마감 중복 실행, 기존 무기한 투표 호환, 전체·파티 채팅 권한과 이벤트 격리다. 테스트는 별도 H2 DB를 사용한다.

완료 검증: 백엔드 전체 124개 테스트(채팅 API 14개 포함), 프런트엔드 154개 테스트, TypeScript 검사, 웹·Android·iOS 번들 생성 통과. 실제 DB 사후 확인에서 `closes_at`의 nullable TIMESTAMP(6) 정의와 `(closed, closes_at)` 인덱스를 확인했고 기존 투표 2개·항목 4개·투표 내역 2개의 건수도 유지되었다.
